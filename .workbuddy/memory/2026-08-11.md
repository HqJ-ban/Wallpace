## 打包成 exe 的环境坑（Wallpace / PyInstaller）

- 机器上有两套 Python：
  - PATH 第一个 = WorkBuddy 自带 `C:\Users\...\workbuddy\binaries\python\versions\3.13.12`（**缺 PySide6 / PyInstaller**）。
  - 系统 Python `C:\Programs\Python\Python313`（**已装齐 PySide6 6.11.1 + PyInstaller 6.21.0**）。
- 现象：双击 `build.bat` "没反应" → 因为脚本里用裸 `python`/`pip`，解析到 WorkBuddy 那套缺依赖的 Python。
- 修复：`build.bat` 顶部加了一行（仅脚本会话内生效，不动全局）：
  `set "PATH=C:\Programs\Python\Python313;C:\Programs\Python\Python313\Scripts;%PATH%"`
  之后裸 `python`/`pip`/`pyinstaller` 都指向系统 3.13，双击可正常打包。
- **关键坑**：系统 Python 下 `python -m pyinstaller` 报 "No module named pyinstaller"，但 `C:\Programs\Python\Python313\Scripts\pyinstaller.exe` 直接调用正常（6.21.0）。metadata 与包错位导致 `-m` 失效。**打包请直接用 pyinstaller.exe，别用 `python -m pyinstaller`**。
- 构建命令：`cd D:\my_project\wallpace && C:\Programs\Python\Python313\Scripts\pyinstaller.exe --name wallpace --windowed --onefile --clean src/main.py`，产物在 `dist\wallpace.exe`。`build.bat` 只打包不启动应用，要另外双击 `dist\wallpace.exe`。
- 运行源码：`C:\Programs\Python\Python313\python.exe src\main.py`。
- 测试（headless）：`QT_QPA_PLATFORM=offscreen python -m pytest -q`（用系统 Python 3.13 跑，103 passed / 1 skipped）。
